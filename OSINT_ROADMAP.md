## Текущие задачи (по приоритету)

### 1. Дозагрузка недостающих вкладок в существующие сырые дампы

**Проблема:** при сборе крупных компаний полный сбор по всем вкладкам может занимать много времени. Часто нужно дособрать только определённые разделы (например, арбитраж или связи), не пересобирая всё заново.

**Задачи:**
- [ ] Добавить в таблицу `raw_dumps` поле `collected_sections` (JSON-массив собранных разделов).
- [ ] Реализовать функцию `loadExistingDump(companyId, type)` для чтения существующего дампа из файла.
- [ ] Реализовать функцию `mergeDumps(existingData, newPartialData)` для объединения данных без потери уже собранных разделов.
- [ ] Добавить в `scrapeRusprofile` опцию `onlySections: string[]` — сбор только указанных вкладок.
- [ ] После досбора обновлять файл дампа и записи в БД (повторный вызов `saveCompanyData` с объединёнными данными).
- [ ] Интегрировать в UI: дать возможность выбрать, какие разделы дособрать, и кнопку «Дополнить дамп».

### 2. Расширение панели управления БД (до уровня Python-скрипта)
