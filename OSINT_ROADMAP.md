## Архитектурные заметки

- Каждый источник данных реализуется как отдельный скрапер.
- Окна создаются по образцу `osintWindow.ts`, IPC — по образцу `osintHandlers.ts`.
- Для одного ИНН (12 цифр) может быть несколько профилей (ИП и ФЛ) — собираются отдельно.
- Дампы ФЛ хранят `summary.ip` — признак наличия ИП.
- Список сохранённых дампов доступен прямо в окне сбора, поддерживает удаление.
- Сырые дампы хранятся в `raw_dumps/{type}/{prefix}/` (type: company/entrepreneur/person/court_case).
- **Унифицированные классы кнопок:** `.osint`, `.osint-soft`, `.osint-destructive`, `.osint-destructive-soft`.
- **Диалоги деталей** визуально повторяют `Panel` (рамка, фон, скругления, футер).
- **mark_false** доступен для `entities`, `relations`, `observations` (не для sources).
- **Табличные компоненты** (`EntitiesTable`, `RelationsTable`, `ObservationsTable`, `SourcesTable`) в `src/components/SIETCH/DatabaseTables/` — используются в главном окне (`compact=false`) и диалогах (`compact=true`).
- **DetailFields** в `src/components/SIETCH/DetailFields.tsx` — единый компонент для «Общих сведений» во всех диалогах. Поддерживает `editing`, `editForm`, `onEditChange` для inline-редактирования без смещения полей.
- **Cross-navigation:** стек диалогов (`dialogStack`) + `dialogCache` + breadcrumb.
- **Каскадный фильтр:** `getRelatedIds(filterType, filterId)` + `relatedIds` + чип в главном окне.
- **origin** ('scraper' | 'manual' | 'import'): миграция добавлена во все 4 таблицы. Скрапер не перезаписывает записи с `origin='manual'`. Любое редактирование или `mark_false` переводит запись в `manual`.
- **Ручное создание** ставит `origin='manual'` по умолчанию.
- **Опасная зона:** полная очистка таблиц / дампов / всего. Защита вводом слова `УДАЛИТЬ`.
- **Справка** (`DatabaseHelp.tsx`) — 8 вкладок с пояснениями, примерами и Cookbook-сценариями.

## Архитектурные заметки

- Каждый источник данных (rusprofile, kad.arbitr, mos-gorsud) реализуется как отдельный скрапер с общим интерфейсом: `start()`, `stop()`, `search(query)`, `collectDetails()`.
- Окна создаются по образцу `osintWindow.ts`, IPC-обработчики — по образцу `osintHandlers.ts`.
- Нормализация расширяется в `osintStorage.ts` (добавляются новые типы сущностей и предикаты связей).
- Сырые дампы для новых источников сохраняются в `raw_dumps/{type}/{prefix}/` с новым типом `court_case` и префиксом по номеру дела.
