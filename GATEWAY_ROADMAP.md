# GATEWAY ROADMAP — Окно "Шлюз" (DeepSeek)

## Цель
Создать новое окно «Шлюз», использующее Playwright для автоматизации входа в чат DeepSeek (https://chat.deepseek.com), отправки сообщений и получения ответов, с повторным использованием сессий и учётных данных.
