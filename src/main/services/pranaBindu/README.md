# PRANA_BINDU — компоненты UI

Зеркало сервисных подмодулей. Один подмодуль — одна папка.

| Папка              | Что показывает                                    |
|--------------------|---------------------------------------------------|
| `shared/`          | Общие мелкие компоненты (карточки, бейджи, зоны)  |
| `Stillsuit/`       | Бег: пульс, темп, экономичность                   |
| `Crysknife/`       | Big-6: ступени, подходы, benchmark                |
| `Mentat/`          | Календарь, неделя, периодизация                   |
| `WaterDiscipline/` | Сон, HRV, светофор восстановления                 |
| `Spice/`           | Графики, синхронизация, провайдеры Zepp           |

Стили — CSS-классы с префиксом `.pb-*`.
Реальная начинка — в 10_UI_DUNA.md. Сейчас только каркас.
