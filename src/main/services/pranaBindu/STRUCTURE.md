# Prana-Bindu — структура сервисного слоя

Все файлы в этой папке — чистый TypeScript, **без импортов Electron**.
Готовы к будущей веб-версии.

## Подмодули

| Папка              | Роль                                                       | Направление  |
|--------------------|------------------------------------------------------------|--------------|
| `core/`            | Зоны, 80/20, движок тренировочных блоков                   | 02_CORE      |
| `stillsuit/`       | Марафон: пульс, темп, экономичность, дыхание               | 04_STILLSUIT |
| `crysknife/`       | Big-6: сила, контроль, сухожилия, нейромышечная работа     | 05_CRYSKNIFE |
| `mentat/`          | Календарь, периодизация, подводка к старту                 | 03_MENTAT    |
| `waterDiscipline/` | Сон, HRV, гидратация, восстановление (арбитр нагрузки)     | 06_WATER     |
| `spice/`           | Аналитика, Google Fit, Zepp, провайдеры                    | 07_SPICE     |
| `melange/`         | Локальная БД `prana_bindu.db` (node:sqlite), миграции      | 08_MELANGE   |

## Правила

- Не смешивать логику разных подмодулей в одном файле.
- Типы — в `types.ts` соответствующего подмодуля.
- Кросс-модульные типы (`HeartRateZone`, `TrainingBlock`) живут
  в `core/types.ts` и импортируются из остальных подмодулей.
- `spice/providers/` — только интерфейс и реестр. Реализации —
  09 (каркас) и 07 (боевая логика).
- UI-тексты и комментарии — на русском.
