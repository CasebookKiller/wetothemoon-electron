### 3. Ключевая диагностика российских API

**GigaChat API (`https://api.giga.chat/v1`):**
- DNS резолвится (155.212.234.167)
- TLS 1.3 handshake ✅
- Сертификат: `CN=giga.chat; O=ООО СалютДевайсы; issuer=Russian Trusted Sub CA`
- Верификация: **проходит через OpenSSL** (CA в `/etc/ssl/certs/`)
- HTTP/2: **403 Forbidden** от nginx (без токена — ожидаемо)
- **В Node.js `fetch failed`** — вероятно, Node.js **не доверяет** Russian Trusted Root CA. Не в trust store Node.
- Фикс: `NODE_EXTRA_CA_CERTS=/etc/ssl/certs/russian_trusted_root_ca.pem` или `rejectUnauthorized: false` в fetch-опциях

**Алиса AI API:**
- `https://llm.api.cloud.yandex.net/v1/models` → **401** (endpoint жив)
- `https://ai.api.cloud.yandex.net/v1/models` → **401** (альтернативный, тоже жив)
- Для probe использовать `/v1/models`, **не** `/v1` (корень = 404)
- Для реальных запросов нужен IAM-токен Yandex Cloud

## 🎯 Приоритеты следующей сессии (2 часа)

### Приоритет 1 (30 мин): Duck.ai как второй канал

`duck.ai` — единственный **200 без логина**, живой, реальный чат.

1. Открыть `https://duck.ai` в Chrome с `--remote-debugging-port=9430`
2. Через patchright подключиться, найти селекторы: input, send button, response container
3. Написать `scripts/recon-duck-smoke.mjs` — отправить «hello», дождаться ответа
4. Если работает — добавить в `ProfileService.provider: 'duck'` (пока как эксперимент)

### Приоритет 2 (30 мин): GigaChat API — фикс Node.js trust store

```bash
# Скачать Russian Trusted Root CA
wget https://gu-st.ru/content/Other/doc/russiantrustedca.pem -O /tmp/russian_ca.pem

# Проверить, что он в системе
ls /etc/ssl/certs/ | grep -i russian

# В Node.js использовать:
NODE_EXTRA_CA_CERTS=/tmp/russian_ca.pem node scripts/recon-free-llms.mjs --filter giga
```

Если 403 → 401 = endpoint доступен из Node.js. Дальше — OAuth-токен (SberID).

### Приоритет 3 (30 мин): Алиса API — IAM-токен

1. Yandex Cloud аккаунт → создать сервисный аккаунт
2. Роль `ai.languageModels.user`
3. IAM-токен: `yc iam create-token`
4. `curl -H "Authorization: Bearer $IAM_TOKEN" https://llm.api.cloud.yandex.net/v1/models`
5. Если 200 — endpoint готов к использованию

## ⚠️ Важно

- **GigaChat web и Алиса web** — работают, но с логином (SberID / Yandex ID). CDP-подход потребует входа в браузере вручную.

- **Алиса API** — 401 без токена, endpoint живой. Проще всего получить IAM-токен.
