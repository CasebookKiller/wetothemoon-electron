## 🐞 Открытые проблемы

### П1. Диалог пропадает при переключении профиля (UX)
**Симптом:** открыт диалог под `request.tel` → переключение на `default` → диалог
исчезает.
**Причина:** `gateway:get-conversations` → `service.getConversations()` — live из Chrome,
не из кэша. При switch Chrome перезапускается → список пуст. `profile-switched` handler
(`GatewayPage.tsx:1183`) сбрасывает диалог.
**Фикс (вариант B):** сайдбар из `cache.listConversations()` без фильтра + бейдж профиля
+ при клике на чужой — `gatewayProfilesActivate` + ждать `profile-switched`.
**Пока не сделано**, минимально — toast-предупреждение при switch.

### П2. `global block present: false` в тесте contextBuilder
**Симптом:** тест `/tmp/test-cont-source.mjs` вывел `global block present: false`,
хотя вывод содержал текст «Fremen Eye — контекст проекта» (это содержимое global).

1. **Три режима:** Web-чат / API-чат / Agents.
2. **Workspace per conversation (вариант C):** в каждом чате свой набор active directions.

6. **Долговременная память:** global → project → submodule → module → direction + state.
   Версионирование через `context_versions`, привязка к git commit.
7. **`key.split('/').length` = уровень** (L0→L4). Не менять.

10. **Правило «найти/заменить»** — правки в стиле find/replace.

```js
import fs from 'node:fs';
import path from 'node:path';
import { pathToFileURL } from 'node:url';

const envPath = path.join(process.cwd(), '.env.local');
if (fs.existsSync(envPath)) {
  for (const line of fs.readFileSync(envPath, 'utf8').split('\n')) {
    const m = line.match(/^\s*([A-Z0-9_]+)\s*=\s*(.*?)\s*$/);
    if (m && !process.env[m[1]]) process.env[m[1]] = m[2].replace(/^["']|["']$/g, '');

const MANIFEST = process.env.CONTEXT_MANIFEST;
if (!MANIFEST) { console.error('❌ CONTEXT_MANIFEST не задан'); process.exit(1); }

const dbUrl = pathToFileURL(path.join(process.cwd(), 'src/main/services/gateway/cache/db.ts')).href;

console.log('included:    ', r.includedNodes);

console.log('\ncontext теги в промпте:');
```
