### Приоритет 1 (обязательно): `handoffBuilder.ts` (1 час)

**Создать файл:** `src/main/services/gateway/handoffBuilder.ts`

**Назначение:** собирает всё состояние проекта в один `.md`.

**Интерфейс:**

```ts
export interface HandoffOpts {
  workspaceKeys: string[];        // activeKeys для contextService.getChain
  taskTitle: string;
  includeGit?: boolean;            // default true — HEAD, branch, status, log -5, diff --stat
  includePreflight?: boolean;      // default true — вывод preflight-check.mjs
  includeSchema?: boolean;         // default true — SCHEMA_VERSION, таблицы v9, counts
  includeRoadmap?: boolean;        // default true — TODO из directions/*.md
  maxContextBytes?: number;        // default 40_000 — обрезка content_md в секции 5
}

export interface BuiltHandoff {
  markdown: string;
  sections: string[];
  bytes: number;
  generatedAt: number;
}

export async function buildHandoff(opts: HandoffOpts): Promise<BuiltHandoff>;
```

**Секции (в порядке):**

1. **`# Handoff — ${new Date().toISOString()}`** — заголовок
2. **`## Task`** — `taskTitle` (зачем этот handoff)
3. **`## Git state`** — `execSync`:
   - `git rev-parse --short HEAD`
   - `git rev-parse --abbrev-ref HEAD`
   - `git status --short`
   - `git log --oneline -5`
   - `git diff --stat HEAD~5 HEAD` (если есть 5 коммитов)
   - submodule: `git -C .. submodule status | grep wetothemoon-electron`
4. **`## Preflight`** — `execSync('node scripts/preflight-check.mjs')`, вывод в `<pre>` блоке
5. **`## Schema`** — прямой SQL:
   - `PRAGMA user_version`
   - список таблиц (`context_*`, `tasks`, `conversations`, `messages`)
   - `COUNT(*)` для `context_nodes`, `context_versions`, `conversations`, `messages`
   - для `context_nodes` — список `key` + `kind` + `version`
6. **`## Context chain`** — `contextService.getChain(workspaceKeys)`:
   - для каждого узла: `### ${key} [${kind}]` + content preview (первые 500 символов)
   - **полный** content **не** включать — иначе .md будет 200K. Только заголовок + первые 500 символов каждого узла.
7. **`## Roadmap`** — `grep -A20 '## ❌ Не сделано\|## TODO\|## Ближайшие' docs/prompts/gateway/MODULE.md directions/*.md` (если есть)
8. **`## Известные проблемы`** — TODO-комментарии из кода (`grep -rn 'TODO\|FIXME' src/main/services/gateway/ | head -20`)

**Обрезка бюджета:** итого ≤ 60K символов. Если больше — обрезать секции 6 и 7.

**Пример реализации** (заготовка, доделать):

```ts
import { execSync } from 'node:child_process';
import path from 'node:path';
import fs from 'node:fs';

import { getGatewayCache } from './cache/db';
import { getChain } from './contextService';

const ROOT = path.resolve(__dirname, '../../../..');  // корень submodule

function sh(cmd: string, cwd = ROOT): string {
  try { return execSync(cmd, { cwd, encoding: 'utf8', timeout: 10000 }).trim(); }
  catch (e: any) { return `[error] ${e.message}\n${e.stdout || ''}${e.stderr || ''}`; }
}

export async function buildHandoff(opts: HandoffOpts): Promise<BuiltHandoff> {
  const sections: string[] = [];
  const parts: string[] = [];

  // 1. Заголовок
  parts.push(`# Handoff — ${new Date().toISOString()}\n`);
  parts.push(`**Task:** ${opts.taskTitle}\n`);
  sections.push('title', 'task');

  // 2. Git state
  if (opts.includeGit !== false) {
    const head = sh('git rev-parse --short HEAD');
    const branch = sh('git rev-parse --abbrev-ref HEAD');
    const status = sh('git status --short') || '(clean)';
    const log = sh('git log --oneline -5');
    const diffstat = sh('git diff --stat HEAD~5 HEAD 2>/dev/null') || '(n/a)';
    const submod = sh('git -C .. submodule status 2>/dev/null | grep wetothemoon-electron') || '(n/a)';
    parts.push(`## Git state\n
- **HEAD:** \`${head}\` (branch \`${branch}\`)
- **Submodule:** ${submod}

### git status --short
\`\`\`
${status}
\`\`\`

### git log --oneline -5
\`\`\`
${log}
\`\`\`

### git diff --stat HEAD~5 HEAD
\`\`\`
${diffstat}
\`\`\`
`);
    sections.push('git');
  }

  // 3. Preflight
  if (opts.includePreflight !== false) {
    const pf = sh('node scripts/preflight-check.mjs 2>&1');
    parts.push(`## Preflight\n\`\`\`\n${pf}\n\`\`\`\n`);
    sections.push('preflight');
  }

  // 4. Schema
  if (opts.includeSchema !== false) {
    const db = getGatewayCache();
    const uv = (db.prepare('PRAGMA user_version').get() as any)?.user_version;
    const tables = (db.prepare(
      "SELECT name FROM sqlite_master WHERE type='table' ORDER BY name"
    ).all() as any[]).map(r => r.name);
    const counts: Record<string, number> = {};
    for (const t of ['context_nodes', 'context_versions', 'conversations', 'messages']) {
      if (tables.includes(t)) {
        counts[t] = (db.prepare(`SELECT COUNT(*) AS c FROM ${t}`).get() as any)?.c ?? 0;
      }
    }
    const nodes = (db.prepare(
      'SELECT key, kind, version FROM context_nodes ORDER BY key'
    ).all() as any[]);

    parts.push(`## Schema\n
- **user_version:** ${uv}
- **Tables (${tables.length}):** ${tables.join(', ')}
- **Counts:** ${Object.entries(counts).map(([k, v]) => `${k}=${v}`).join(', ')}

### context_nodes (${nodes.length})
| key | kind | version |
|---|---|---|
${nodes.map(n => `| ${n.key} | ${n.kind} | ${n.version} |`).join('\n')}
`);
    sections.push('schema');
  }

  // 5. Context chain
  const chain = getChain(opts.workspaceKeys);
  const maxPerNode = 500;
  const chainMd = chain.map(n => {
    const preview = (n.contentMd || '').slice(0, maxPerNode);
    const truncated = (n.contentMd || '').length > maxPerNode ? '\n\n_(обрезано)_' : '';
    return `### ${n.key} [${n.kind}] v${n.version}\n\n${preview}${truncated}`;
  }).join('\n\n---\n\n');
  parts.push(`## Context chain (${chain.length} узлов)\n\n${chainMd}\n`);
  sections.push('context');

  // 6. Roadmap + TODOs
  if (opts.includeRoadmap !== false) {
    const todos = sh("grep -rn 'TODO\\|FIXME' src/main/services/gateway/ src/main/ipcHandlers/gatewayHandlers.ts 2>/dev/null | head -20") || '(нет)';
    parts.push(`## Roadmap / TODOs\n\`\`\`\n${todos}\n\`\`\`\n`);
    sections.push('roadmap');
  }

  let markdown = parts.join('\n');
  if (markdown.length > (opts.maxContextBytes ?? 60_000)) {
    markdown = markdown.slice(0, opts.maxContextBytes ?? 60_000) + '\n\n_[handoff обрезан по бюджету]_';
  }

  return {
    markdown,
    sections,
    bytes: Buffer.byteLength(markdown, 'utf8'),
    generatedAt: Date.now(),
  };
}
```

```ts
ipcMain.handle('gateway:export-handoff', async (_e, opts?: {
  moduleId?: string;
  workspaceKeys?: string[];
  taskTitle?: string;
}) => {
  try {
    const api = (await import('../services/gateway/handoffBuilder'));
    const activeKeys = opts?.workspaceKeys ?? (
      process.env.ACTIVE_WORKSPACE_KEYS?.split(',').map(s => s.trim()).filter(Boolean) ?? []
    );
    if (activeKeys.length === 0) {
      return { success: false, error: 'ACTIVE_WORKSPACE_KEYS пуст' };
    }
    const r = await api.buildHandoff({
      moduleId: opts?.moduleId ?? 'gateway',
      workspaceKeys: activeKeys.length > 0 ? activeKeys : undefined,
      taskTitle: opts?.taskTitle ?? 'Продолжение работы',
      rootPath: app.getAppPath(),
    });
    // Сохранить в userData/handoff/
    const { app } = require('electron');
    const dir = path.join(app.getPath('userData'), 'handoff');
    fs.mkdirSync(dir, { recursive: true });
    const fname = `handoff-${new Date().toISOString().replace(/[:.]/g, '-')}.md`;
    const fpath = path.join(dir, fname);
    fs.writeFileSync(fpath, r.markdown, 'utf8');
    return {
      success: true,
      data: { path: fpath, bytes: r.bytes, sections: r.sections },
    };
  } catch (e) {
    return { success: false, error: (e as Error).message };
  }
});
```

## Известные подводные камни

1. **`__dirname` в ESM** — если `handoffBuilder.ts` собирается как ESM, `__dirname` не будет. Использовать `import.meta.url` + `path.dirname(fileURLToPath(import.meta.url))` **или** передавать `ROOT` из вызывающего кода (из `gatewayHandlers.ts`, где `app.getAppPath()` доступен).

2. **`require('electron')` в IPC** — `gatewayHandlers.ts` скорее всего CJS (проверь `package.json` → `"type"`). Если ESM — использовать `import { app } from 'electron'` на верхнем уровне.

3. **`file://` fetch из renderer** — Electron по умолчанию **блокирует** `fetch('file://')` в renderer. **Решение:** возвращать `markdown` в IPC-ответе, не читать из файла:
   ```ts
   // В gatewayHandlers.ts:
   return { success: true, data: { path: fpath, bytes: r.bytes, sections: r.sections, markdown: r.markdown } };
   // В UI:
   await navigator.clipboard.writeText(r.data.markdown);
   ```
   **Так надёжнее — используй этот вариант.**

4. **`execSync` с русскими путями** — `cwd` с кириллицей работает, но `encoding: 'utf8'` обязателен (иначе кракозябры).

5. **Размер handoff** — если 60K, `.md` большой. В UI показать `bytes`, чтобы понимать, влезет ли в контекст модели (DeepSeek ~200K токенов = ~800K символов, влезет с запасом).
