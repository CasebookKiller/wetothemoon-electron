# Чат: Графики и визуализация данных

> Обновлено: 2026-09-30
> Статус: черновик, обсуждается.

## Цель

Единая библиотека графиков и визуализаций для всех модулей
приложения. Переиспользуемые компоненты + соглашение о стилях.
Графики должны уметь:
- работать с большими потоками (10 000+ точек);
- показывать несколько каналов одновременно;
- окрашивать линии/маркеры по значению канала (HR-зоны);
- сохранять читаемость на тёмной теме;
- принимать данные через props (глупые компоненты).

## Что уже есть

`RunStreamsChart.tsx` — прототип:
- Chart.js через PrimeReact `Chart`.
- X-ось: `secT` / `distM` / `poly_sec_t` / `sec_t` / `dist_m`.
- Y-канал: любой числовой массив из payload.
- Пороговые линии (LTHR / HRmax).
- Ручной выбор X/Y через Dropdown.
- Предупреждение о «плоских» данных.

## Что нужно улучшить

### 1. Заливка под кривой и линия среднего

- Линейный градиент под линией (accent → transparent).
- Пунктирная горизонтальная линия на `avg`.

### 2. Мультиканал

- Toggle над графиком: одновременно показывать HR + темп + высоту.
- Каждый — своя Y-ось (слева / справа).
- Общая X-ось.

### 3. Окраска по значению (HR-зоны)

- Линия HR сегментируется по зонам.
- Цвет сегмента: синий (легко) → зелёный → оранжевый → красный.
- Границы зон из `profile.lthr` / `profile.max_hr`.
- Сглаживание переходов.

### 4. Интерактивность

- Zoom/pan (`chartjs-plugin-zoom` уже установлен).
- Tooltip: показывает все активные каналы в одной точке.
- Crosshair — вертикальная линия на курсоре.

### 5. Полоса зон под графиком

- Внизу графика — горизонтальная полоса шириной с график.
- Сегменты: время в каждой зоне.
- Клик по сегменту — подсветка соответствующего участка на графике.

### 6. Компонент в COMMON

- Пропсы-only: `data`, `channels`, `xField`, `onHover`, `theme`.
- Никаких `api.pb.*` внутри.
- Один `<Chart>` для разных модулей.

## Связанные фичи

### Карта с окраской трека

`GpsMapView.tsx` — сейчас трек одного цвета.
Планируем окраску **по значению канала**:
- HR → 5 цветов по зонам;
- скорость / темп → градиент от синего (медленно) к красному
  (быстро);
- каденс → градиент;
- высота → градиент от синего (низко) к коричневому (высоко).

**Как реализовать:** MapLibre `line-gradient` на сегментах.
Разбиваем LineString на отрезки по 10–20 точек, каждому сегменту
свой цвет.

**Синхронизация с графиком:** курсор на графике → подсветка
соответствующей точки на карте. И наоборот.

## Первый вопрос к чату

Куда двигать график — делать **один универсальный** `<StreamChart>`
с кучей опций, или **набор специализированных** (`<HrChart>`,
`<PaceChart>`, `<ElevationChart>`)? Мой голос — универсальный,
потому что каналы у нас однотипные. Но с возможностью конфигурации
через пропсы.
