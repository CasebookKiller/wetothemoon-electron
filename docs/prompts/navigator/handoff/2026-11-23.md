## 🏗 Архитектура backend (для продолжения)

### Поток вызова

```
Renderer → window.electronAPI.navigator.send(profileId, msg)
         → ipcMain 'navigator:send'
         → initTools()                              [toolRegistry]
         → getBrowserPool()                         [gatewayHandlers, единый инстанс]
         → resolve(profileId, pool)                 [sessionManager]
             ├─ ProfileService.getInstance().get(id) → provider
             ├─ PROVIDER_TO_TOOL[provider] → toolId
             ├─ pool.acquire(profileId) → page      [Gateway, playwright-core Page]
             ├─ (as unknown as Page)                [TD-NEW каст, patchright]
             └─ tool.connect?.(page)                [GigaChat: goto giga.chat]
         → tool.send(page, { message })             [llmTool → adapter.sendMessage]
         → for await chunk → event.sender.send('navigator:chunk', { profileId, chunk })
```
