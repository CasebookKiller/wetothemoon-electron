## 🎯 Следующее — История диалогов в UI (вариант B, ~45–60 мин)

### Задача

В sidebar показывать **диалоги** (не только профили): список сессий, которые уже есть в GigaChat-аккаунте. Пользователь хочет «историю из оригинала» — то есть те же диалоги, что он видит в `giga.chat/sessions/…` в браузере, **в нашем UI**.

### Архитектурное решение (гибрид: БД Gateway + `getConversations(page)`)

**Почему не только `getConversations(page)`:**
- Работает **только когда браузер запущен** (нужен `page`).
- Не кэширует — каждый вызов = парсинг DOM.
- Не даёт истории **сообщений** (только список диалогов).
- Не универсально для провайдеров без DOM (будущие HTTP-адаптеры).

**Почему не только БД:**
- БД знает только те диалоги, которые **прошли через наш UI**.
- «История из оригинала» (то, что уже есть в аккаунте до Navigator) в БД отсутствует.

**Гибрид — правильно:**
1. **БД `gateway.db`** — основное хранилище (`conversations`, `messages`). Переиспользуем существующий `GatewayCacheService` (или обобщаем его для Navigator). Наполняется при стриме (`navigator:send` → запись чанков после `done`).
2. **`getConversations(page)`** — синхронизация метаданных из браузера. Кнопка «Обновить из GigaChat» в sidebar.
3. **UI** — список из БД (мгновенно, без браузера) + кнопка «Обновить» (sync с DOM).

## 📚 Уроки сессии

1. **GigaChat = HTML из DOM, DeepSeek = markdown-строка из API.** Решение — `format?: 'text' | 'markdown' | 'html'` в `MessageChunk`, UI рендерит по нему.
2. **`THINKING_PREFIXES` нужно расширять по мере обнаружения.** «Думаю над ответом», «Ищу информацию в интернете», «Анализирую» — всё статусы. Список — в `adapter.ts`.
3. **`stableTicks` должен уважать `stillThinking`.** Иначе premature `done` на статусе.
4. **При правке общих типов — читать целиком.** Урезанная `MessageChunk` сломала бы Gateway.
5. **Подписка на IPC — в `useEffect`, а не в `onSend`.** Иначе `unsub` не снимается, `busy` залипает.
6. **Safety-таймер обязателен.** Backend может не прислать `done` — без таймера UI зависает.
7. **Prism-токены — scoped через `.navigator-markdown`.** Не тащим глобальный `prism-tomorrow.css`, не конфликтуем с Gateway.
8. **GigaChat-HTML содержит свои class-префиксы (`CodeBlock-styled__…`), sc-хеши меняются.** Использовать `[class*="…"]`, не хардкодить хеши.
